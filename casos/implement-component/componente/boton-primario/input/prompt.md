Genera un botón primario de tamaño estándar con el texto "Enviar".

Usa la librería DESY correspondiente y el macro de la librería para el botón.
El botón es la acción principal de un formulario, así que debe llevar la
variante primaria. No añadas props que el macro no acepte.

Escribe el componente en un fichero nuevo dentro de `src/` (por ejemplo,
`src/boton-enviar-primario.html`). Lo que quede solo en el chat no cuenta.
